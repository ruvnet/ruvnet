## Forecast

Prediction, 85% confidence by 2026-12-15: agent registries and provenance ledgers will increasingly bind opaque cursors to a snapshot or query identity instead of exposing reusable offsets. It passes only if at least two primary agent-memory, MCP or registry implementations newly publish snapshot-, revision- or query-bound invalidation semantics. The [July 2026 MCP pagination guidance](https://modelcontextprotocol.io/specification/2026-07-28/server/utilities/pagination) already requires clients to treat cursors as opaque, while [MCP caching guidance](https://modelcontextprotocol.io/specification/2026-07-28/server/utilities/caching) documents cross-page consistency limits; [Portable Agent Memory](https://arxiv.org/abs/2605.11032) adds evidence that provenance-bound memory transfer is an active research direction. This forecast goes beyond those established results. No previous forecast horizon expired today.

Next hypothesis: add explicit snapshot revision metadata to every page and test whether hosts recover correctly from mid-session snapshot rollover without returning mixed provenance.
