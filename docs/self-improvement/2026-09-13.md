## MetaHarness loop and measured evidence

The [acceptance plan](2026-09-13-plan.json) was frozen before implementation. Held-out host-routing checks improved from 3/6 to 6/6. Eight test groups, schema validation, package closure, CLI, in-memory MCP and stdio MCP checks passed. MetaHarness 0.4.16 reported 6/6 hard constraints for both the baseline and candidate plugin surfaces, with unchanged heuristic scores. Those scores are not the proof of improvement.

Fifteen interleaved baseline/candidate pairs measured 10,000 discovery calls and 20 cold CLI starts per process. Median discovery p95 changed from 0.001262 ms to 0.000992 ms; cold CLI p95 changed from 70.722 ms to 73.264 ms, a 3.59% regression within the 20% plus 5 ms gate; resident memory changed by -176,128 bytes. An earlier unpaired run showed a contradictory 44.4% discovery regression, so the sub-microsecond difference is treated as measurement noise rather than a speed claim. [Raw benchmarks](2026-09-13-benchmarks.json) and [machine-readable evidence](2026-09-13-evidence.json) preserve both the gate and limitation.

The deep Ruflo 3.25.6 code and dependency scans plus npm audit reported zero findings. Manual tracked-file credential patterns also returned zero files. The scanner reported only five files for its secret pass and four for its STRIDE pass; this is limited coverage, not a claim that the system is completely secure. The primary residual risks are stale reviewed data, untrusted linked content, and clients treating annotation hints as enforcement.

## Memory, WASM and GNN decision

RuVector's observed source documents persistent `VectorDB`, graph retrieval, feedback, WASM adapters, and GNN reranking; AgentDB documents feedback-driven retrieval and WASM fallback. Neither source changed today. No vector database, GNN training, persistent learning, or WASM acceleration was added or claimed.

The corpus has ten projects and six change records, below the precommitted 100-record gate. Exact lookup remains deterministic and materially simpler. A future experiment is eligible only with a leakage-free split, at least 10 percentage points of task-success gain over exact search, p95 below 20 ms, and total memory below 128 MB.

## Forecast

**30 days, 85% confidence.** Host-specific MCP profiles will become necessary for review-sensitive integrations when legacy service schemas expose broader credentials or authority. This passes if at least two target hosts require observably different endpoint, tool-schema, or authorization profiles in reproducible integration tests. Ruflo's two-profile gateway is the first confirming observation, not completion of the forecast.

**90 days, 75% confidence, prior forecast still open.** Hosts will increasingly depend on machine-readable provenance, correct mutability hints and bounded catalog caching. The MCP 2026-07-28 release established stateless requests, header routing, cache hints and authorization hardening. This passes when two target hosts surface or enforce these fields. [MCP release](https://blog.modelcontextprotocol.io/posts/2026-07-28/).

**180 days, 70% confidence.** Useful agent memory will require task-regime routing rather than one universal retrieval substrate. A controlled 2026 preprint found that no substrate dominated and that excessive retrieval could hurt sequential decisions; SMMBench separately evaluates cross-source composition and memory-grounded action. This passes if a held-out RuVnet corpus of at least 100 records shows different winners across factual and sequential-action tasks while meeting the fixed latency and memory gates. [Harness the Memory](https://arxiv.org/abs/2608.15008) · [SMMBench](https://arxiv.org/abs/2605.15710).
