# ADR 001: A bounded entry point to the RuV Stack

Status: accepted for this implementation. Date: 2026-09-12.

## Specification

Input: user goal, target host and known project ID. Output: project selection, source links, connection guidance and an advisory integration plan. Provide Claude and Codex manifests, a repository marketplace, portable skills, and a tested local CLI/MCP. Keep the profile introduction brief. Preserve existing profile content and metric automation.

## Pseudocode

Tokenize the goal, consult the precomputed project index, rank by token overlap, return matches with maturity boundaries. Do not infer certainty or execute suggested commands. Route remote federation requests to the already hosted x.ruv.io connector. Return fixed argv templates for MetaHarness, with no user input interpolation.

## Architecture

A dated JSON catalog is shared by four skills and a dependency-light core. The CLI loads the official, pinned MCP SDK only when starting stdio. SDK transport negotiation replaces a hand-written JSON-RPC implementation. Host-specific marketplace schemas point at the same plugin directory. Installed skills use plugin-local relative resources.

The local companion has no network call, arbitrary file read, credential handling, shell execution, installer, publishing tool or mutable memory. It loads only its own catalog. The MCP transport accepts at most 64 KiB per line before exiting. The host supervises process lifetime and aggregate resource use.

The remote connector is a separate authority boundary. OAuth controls gateway actions; local Nostr keys control personal signatures. This repository does not deploy new tools to x.ruv.io or grant host permissions. Do not imply that a shared marketplace makes all host capabilities interchangeable.

## RuV Stack optimization

Ten static records do not justify a vector database or native runtime. An in-memory token index avoids embedding costs and keeps ordinary CLI startup free of SDK loading. Use RuVector/AgentDB only for a measured semantic or persistent retrieval workload. Use the real MetaHarness and Ruflo workflows when execution is authorized; this companion remains a planner, not a substitute implementation.

## Refinement and completion

Tests cover representative routing, invalid and hostile input, all tools/resources/prompts through the official SDK, subprocess stdio and oversized frames. Benchmarks disclose corpus and sample sizes and exclude model quality and network latency. Dependency audit and a scoped Ruflo scan supplement manual boundary review. See VALIDATION.md for results and limitations.

## Rollback

Revert the entrypoint commit. Remove its plugin from the host and its local MCP configuration. Revoking OAuth is a separate host/provider action. No service deployment or data migration is introduced.
