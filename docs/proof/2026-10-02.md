## Source and release boundaries

Ruflo's [3.50.0 release](https://github.com/ruvnet/ruflo/releases/tag/v3.50.0) reports opt in Mods, 16 Mods engine tests, 38 swarm tests, 3 ruOS tests, and a 117 entry release witness. Those are upstream reports. The inspected main commit [`1c78a51d`](https://github.com/ruvnet/ruflo/commit/1c78a51d42166cc111e5c24bcf0bb89c51295105) includes later installation defaults and repair work. Release behavior is not inferred from the newer README.

RVF's [wire tests](https://github.com/ruvnet/RuVector/blob/5a93328f2fceb0307c25929ed38cd7a0911fdf00/crates/rvf/rvf-wire/tests/wire_contract_golden.rs) pin segment bytes, a root manifest checksum, and tail discovery. Its [witness tests](https://github.com/ruvnet/RuVector/blob/5a93328f2fceb0307c25929ed38cd7a0911fdf00/crates/rvf/rvf-runtime/tests/witness_e2e.rs) exercise signed evidence, recorded policy outcomes, costs and tamper rejection. These establish the presence of specific tests at a revision. They do not prove every RVF backend or deployment path behaves identically.

RVForge's [contract](https://github.com/ruvnet/RuVector/blob/5a93328f2fceb0307c25929ed38cd7a0911fdf00/npm/packages/rvforge/README.md) explicitly says local build output is staged and not runnable. Native installer assembly and platform signing are separate. The profile uses that narrower boundary.

MetaHarness's [multi generation protocol](https://github.com/ruvnet/metaharness/blob/9ce8b8dd89045c3b9a1f809ae58f3589029db4a4/docs/adrs/ADR-318-multi-generation-improvement-proof.md) separates verifier qualification, synthetic lineages, bounded evidence and independent confirmation. A working verifier is not proof of recursive self improvement. Likewise APx's tutorial does not measure rUv's productivity, and rGi does not demonstrate AGI.

## Reproduce the profile check

From this repository:

```sh
node scripts/verify-profile.mjs
```

The check recomputes GitHub totals from the captured inventory, verifies the six new histories are represented, reconciles registry counts and download populations, checks the rendered metric rows, validates local links in the refreshed documents, and checks SHA256 fingerprints of the frozen snapshot files. A mismatch exits nonzero. The check passed for this update with 42 local links, 21 source receipts and six frozen snapshots. A deliberately altered snapshot was rejected. The renderer was idempotent, and a synthetic future registry refresh updated the README, package index and aggregate totals consistently. The workflow JavaScript passed syntax validation.

To reproduce a new inventory from live services, paginate these official endpoints and retain a new observation timestamp:

```text
https://api.github.com/users/ruvnet
https://api.github.com/users/ruvnet/repos?type=owner&per_page=100&page=1
https://registry.npmjs.org/-/v1/search?text=maintainer%3Aruvnet&size=250&from=0
https://crates.io/api/v1/crates?user_id=339999&per_page=100&page=1
```

Live values can differ from a frozen snapshot. Source fingerprints identify the inspected bytes. They are not trusted signatures, independent attestations, or legal priority determinations.
