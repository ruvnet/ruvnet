# Visual profile

The README dashboard is an animated SVG generated from the published JSON in this repository. SVG images embedded in a GitHub README do not fetch JSON themselves. Rendering happens before commit; the resulting image contains the values and their source dates.

| Visual | Source |
| --- | --- |
| npm annual events, package cohort, monthly series | `data/registry-stats.json` |
| Rust crate inventory and cumulative events | `data/registry-stats.json` |
| GitHub account totals and flagship stars | `data/github-stats.json` |
| Minimum published artifact inventory | `data/metrics.json` |
| Baseline flagship stars | `data/snapshots/2026-10-02/github-baseline-2026-09-07.json` |

The annual rolling window differs from the complete calendar months in the chart. Package inventory can differ from the download cohort. Star traces connect two snapshots, are normalized independently per panel, and do not represent daily observations. Numbers remain fixed during animation. Orbit rings, signals, loading stages and constellation connections are decorative, not live telemetry or proof of integration.

## Regenerate

From the repository root, using Python 3 with its standard library:

```sh
python3 scripts/render-visual-profile.py
python3 scripts/render-constellation.py
node scripts/verify-profile.mjs
```

The dashboard's layout and motion source is `scripts/templates/ruvnet-dashboard.svg`. Its sample text is replaced by the renderer from the JSON sources on every build. Edit the renderer when adding data fields. Chapter banners and the constellation map are generated by `scripts/render-constellation.py`.

The existing weekly registry refresh also renders the dashboard. A separate daily workflow and source-change trigger regenerate visuals from committed data; they do not pretend that unchanged source measurements are fresh. GitHub measurements retain their own verification date. Images may remain cached briefly after a commit.

All SVGs are self-contained, with no scripts, external fonts or network calls. A `prefers-reduced-motion` rule disables animation. The dashboard has a once-only intro, followed by looping flourishes. Clients that suppress SVG animation may show a static frame; the Markdown tables remain the accessible source for the metrics and project links.

## Visual reading order

The profile leads with the dashboard, then the constellation, a short capability table, twelve linked project cards and practical entry points. Registry, memory and evidence chapters combine SVG illustrations with selectable Markdown text. Historical catalogs remain inside an expandable archive.

The cards and process diagrams illustrate roles without duplicating changing metric values. All illustrations are regenerated by `scripts/render-constellation.py`, which the existing visual workflow runs after source changes.

Motion uses role specific radar sweeps, floating memory layers, routed signals, orbital particles and evaluation traces. Titles and descriptions stay still. The capability cutaway is a conceptual illustration, not a benchmark or live system monitor. Reduced motion disables these effects.
